## 2. الشرح العميق والمبسط 💡

### أولاً: ما هي دوال لامدا (Lambda Functions)؟
هي دوال **مجهولة الاسم (Anonymous Functions)**؛ أي أنها تُكتب بدون اسم `def`. تُعرّف في سطر واحد باستخدام الكلمة المفتاحية `lambda`.

* **الصيغة العامة:**
  ```python
  lambda arguments: expression
  ```
  * `arguments`: المدخلات (يمكن أن تكون متعددة مفصولة بفواصل).
  * `expression`: العملية التي يتم تنفيذها وإرجاع ناتجها تلقائياً (بدون الحاجة لكتابة `return`).

---

### ثانياً: الدوال عالية الرتبة (Higher-Order Functions)
في بايثون، **الدوال هي كائنات من الدرجة الأولى (First-Class Citizens)**. هذا يعني أنه يمكنك:
1. تخزين الدوال في متغيرات.
2. تمرير الدوال كمدخلات لدوال أخرى.
3. إرجاع الدوال كنواتج من دوال أخرى.

الدالة التي تأخذ دالة أخرى كمدخل (أو تُرجع دالة) تُسمى **Higher-Order Function**. وأشهرها في بايثون:
* `map(function, iterable)`: لتطبيق دالة معينة على كل عنصر في قائمة (أو أي كائن قابل للتكرار).
* `filter(function, iterable)`: لتصفية العناصر بناءً على شرط معين (يعيد True أو False).
* `from functools import reduce`: لتجميع عناصر القائمة وتقليصها إلى قيمة واحدة (مثل جمع كل العناصر أو ضربها).

## 3. أمثلة أكواد برمجية نظيفة وتطبيقات حقيقية 💻

دعونا نرى كيف نعمل مع `lambda` و `map`, `filter`, `reduce` من خلال تطبيق عملي لنظام خصومات في متجر إلكتروني.

```python
from functools import reduce

# قائمة بأسعار المنتجات في المتجر
prices = [120, 45, 300, 85, 200, 15]

print("--- 1. تطبيق الخصم باستخدام map و lambda ---")
# نفترض أننا نريد تطبيق خصم 10% على جميع المنتجات
# المعادلة: السعر * 0.9
discounted_prices = list(map(lambda p: p * 0.9, prices))
print(f"الأسعار الأصلية: {prices}")
print(f"الأسعار بعد الخصم: {discounted_prices}")


print("\n--- 2. تصفية المنتجات الغالية باستخدام filter و lambda ---")
# نريد فقط المنتجات التي يقل سعرها بعد الخصم عن 100
affordable_prices = list(filter(lambda p: p < 100, discounted_prices))
print(f"الأسعار الاقتصادية (أقل من 100): {affordable_prices}")


print("\n--- 3. حساب إجمالي المبيعات باستخدام reduce و lambda ---")
# نريد حساب المجموع الكلي للأسعار بعد الخصم
total_revenue = reduce(lambda x, y: x + y, discounted_prices)
print(f"إجمالي قيمة المنتجات بعد الخصم: {total_revenue}")
```
