## 💡 2. الشرح العميق والمبسط: كيف نفكر كمبرمجين؟

عندما يطلب منك بناء برنامج، يجب أن تفكر كمهندس برمجيات مقسمًا المشكلة إلى خطوات منطقية (Algorithms):

1.  **الترحيب بالمستخدم:** لجعل البرنامج يبدو احترافياً.
2.  **استقبال المدخلات:** نحتاج إلى رقمين من المستخدم، ونوع العمليات الحسابية التي يريد إجرائها.
3.  **إجراء المعالجة (Processing):** تطبيق العمليات الحسابية بناءً على طلب المستخدم.
4.  **عرض النتيجة (Output):** طباعة الناتج بشكل واضح وجميل.

### ⚠️ ملاحظة تقنية هامة جداً:
تذكر دائماً أن دالة `input()` في بايثون **دائماً** تعيد النتيجة على شكل **نص (String)**، حتى لو أدخل المستخدم رقماً! لذلك، سنحتاج لاستخدام دالة التحويل `float()` لكي نتمكن من إجراء العمليات الحسابية الرياضية.

## 💻 3. التطبيق العملي: بناء الآلة الحاسبة الذكية

إليك الكود الكامل والنظيف للآلة الحاسبة. اقرأ التعليقات (Comments) بعناية فهي تشرح كل خطوة:

```python
# ==========================================
# مشروع الكابسستون: آلة حاسبة بسيطة
# CodeU - Python for Beginners
# ==========================================

print("-----------------------------------")
print("   مرحباً بك في حاسبة CodeU الذكية!   ")
print("-----------------------------------")

# الخطوة 1: استقبال الرقم الأول وتحويله إلى عدد عشري (Float)
num1 = float(input("أدخل الرقم الأول: "))

# الخطوة 2: استقبال العملية الحسابية المطلوبة
print("اختر العملية (+, -, *, /): ")
operation = input("العملية: ")

# الخطوة 3: استقبال الرقم الثاني
num2 = float(input("أدخل الرقم الثاني: "))

# الخطوة 4: تنفيذ العملية بناءً على اختيار المستخدم
if operation == "+":
    result = num1 + num2
    print(f"النتيجة: {num1} + {num2} = {result}")

elif operation == "-":
    result = num1 - num2
    print(f"النتيجة: {num1} - {num2} = {result}")

elif operation == "*":
    result = num1 * num2
    print(f"النتيجة: {num1} * {num2} = {result}")

elif operation == "/":
    # شرط إضافي لمنع القسمة على الصفر وحماية البرنامج من الانهيار!
    if num2 == 0:
        print("خطأ: لا يمكن القسمة على الصفر يا صديقي! 🚫")
    else:
        result = num1 / num2
        print(f"النتيجة: {num1} / {num2} = {result}")

else:
    print("عملية غير صالحة! يرجى تشغيل البرنامج وإدخال عملية صحيحة.")

print("\nشكراً لاستخدامك حاسبة CodeU. إلى لقاء في درس قادم! 👋")
```

## 🛠️ 4. تمرين عملي يمهد للخطوة القادمة

لأننا نؤمن في **CodeU** بأن المبرمج لا يتعلم إلا بالكتابة بنفسه، ندعوك لإنجاز هذا التحدي:

### 🎯 التحدي المطلوب منك:
قم بتطوير الكود السابق لإضافة **عملية حسابية جديدة** لم نتحدث عنها في الدرس، وهي **حساب الأسس (Exponentiation)** باستخدام معامل بايثون (`**`).
* اجعل الحاسبة تسأل المستخدم عن رقم أساس ورقم أُس.
* اطبع النتيجة بشكل جميل باستخدام الـ `f-string`.

> **💡 تلميح للمستقبل (القسم القادم):** في الكود أعلاه استخدمنا أدوات اتخاذ القرار (`if`, `elif`, `else`). هذا هو بالضبط موضوعنا في **القسم القادم (Control Flow)**، حيث سن تتعمق أكثر في كيفية جعل برامجنا أكثر ذكاءً ومرونة!
