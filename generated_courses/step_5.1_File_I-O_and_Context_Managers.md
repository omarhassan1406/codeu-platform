## 2. الشرح العميق والمبسط 🧠

### أولاً: التعامل التقليدي مقابل مدراء السياق (Context Managers)
في الماضي (أو في لغات أخرى)، لكي تقرأ ملفاً، كنت تحتاج إلى:
1. فتح الملف (`open()`).
2. تنفيذ العمليات (قراءة/كتابة).
3. **إغلاق الملف يدوياً** (`close()`). 

الخطوة الثالثة غالباً ما تنسى، مما يؤدي إلى تسريب في الموارد (Resource Leaks) وتلف الملفات. 
**الحل في بايثون؟** استخدام الكلمة المفتاحية `with`، وهي ما يُعرف بـ **Context Manager**؛ فهي تتولى فتح وإغلاق الملف تلقائياً وبأمان تام، حتى لو حدث خطأ أثناء قراءة الملف.

### ثانياً: قراءة وكتابة ملفات النصوص (Text Files)
بايثون تجعل التعامل مع الملفات أمراً في غاية السهولة باستخدام الدالة المدمجة `open(filename, mode)` حيث أن الأوضاع (Modes) الأساسية هي:
- `'r'` للإقرار (Read) - وهو الوضع الافتراضي.
- `'w'` للكتابة (Write) - يقوم بمسح المحتوى القديم وكتابة محتوى جديد.
- `'a'` للإلحاق (Append) - يضيف البيانات الجديدة في نهاية الملف دون مسح القديم.

### ثالثاً: التعامل مع ملفات الـ CSV
البيانات الجدولة هي عصب تطبيقات العالم الحقيقي. بايثون توفر مكتبة مدمجة رائعة اسمها `csv` لقراءة وكتابة هذه الملفات بسهولة.

### رابعاً: إدارة المسارات باحترافية باستخدام `pathlib`
عليك أن تتوقف فوراً عن استخدام النصوص التقليدية لكتابة مسارات الملفات (مثل `"C:\\Users\\...\\file.txt"` أو `"data/file.txt"`) لأنها تسبب مشاكل بين أنظمة التشغيل (Windows vs. Mac/Linux). البديل العصري والأقوى هو استخدام مكتبة `pathlib`.

## 3. أمثلة أكواد برمجية نظيفة وتطبيقات حقيقية 💻

إليك سيناريو حقيقي: لنفترض أننا نريد تسجيل سجل دخول المستخدمين (Log) وحفظ نتائجهم في ملف CSV.

### المثال الأول: استخدام `with` لملفات النصوص
```python
# كتابة سجل دخول المستخدم
with open("user_logs.txt", "w", encoding="utf-8") as file:
    file.write("تسجيل الدخول الأول: النظام يعمل بكفاءة.\n")
    file.write("المستخدم 'أحمد' قام بتسجيل الدخول.\n")

print("تمت الكتابة بنجاح!")

# قراءة الملف بطريقة آمنة
print("\n--- قراءة محتوى السجل ---")
with open("user_logs.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

### المثال الثاني: التعامل مع ملفات CSV
```python
import csv

# بيانات لدرجات الطلاب سنقوم بحفظها
students_data = [
    ["Name", "Subject", "Score"],
    ["سارة", "Python", 95],
    ["محمد", "Databases", 88],
    ["ليلى", "Algorithms", 92]
]

filename = "grades.csv"

# كتابة البيانات إلى ملف CSV
with open(filename, mode="w", newline="", encoding="utf-8") as csv_file:
    writer = csv.writer(csv_file)
    writer.writerows(students_data)

print(f"تم إنشاء ملف الـ CSV بنجاح في: {filename}")

# قراءة البيانات من ملف الـ CSV وعرضها
print("\n--- قراءة درجات الطلاب ---")
with open(filename, mode="r", encoding="utf-8") as csv_file:
    reader = csv.reader(csv_file)
    for row in reader:
        print(f"الطالب: {row[0]} | المادة: {row[1]} | الدرجة: {row[2]}")
```

### المثال الثالث: إدارة المسارات بذكاء باستخدام `pathlib`
```python
from pathlib import Path

# إنشاء مسار آمن بغض النظر عن نظام التشغيل
data_dir = Path("app_data")
data_dir.mkdir(exist_ok=True)  # إنشاء المجلد إذا لم يكن موجوداً

file_path = data_dir / "config.txt"

# كتابة بيانات في المسار الجديد
file_path.write_text("API_KEY=12345_SECURE_KEY\nDEBUG=True", encoding="utf-8")

# قراءة البيانات باستخدام pathlib مباشرة
print(f"\nقراءة الملف من المسار: {file_path.resolve()}")
print(file_path.read_text(encoding="utf-8"))
```
