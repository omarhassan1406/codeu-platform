# الدرس [5.4]: الفهم المتقدم (Advanced Comprehensions)

### 1. ربط سريع بما تم تعلمه سابقاً 🔗
في الأقسام السابقة، تعلمت كيف تستخدم الحلقات التكرارية (Loops) مثل `for` و `while` لمعالجة البيانات، وتعرفت على الأساسيات البسيطة للـ *List Comprehensions* لتوليد قوائم جديدة بطريقة مختصرة وأنيقة. 
اليوم، سنرتقي بهذه المهارة إلى المستوى التالي! سنتعلم كيف نكتب شروطاً معقدة، وكيف نطبق الفهم (Comprehension) ليس فقط على القوائم (Lists)، بل على القواميس (Dictionaries) ومجموعات البيانات (Sets)، وكيف نقوم بتحويل كود طويل ومعقد إلى سطر واحد نظيف وفعال (Pythonic Way).

---

### 2. الشرح العميق والمبسط 🧠

الـ **Comprehension** في بايثون ليست مجرد "اختصار كتابة"، بل هي أداة قوية مبنية داخل لغة بايثون لتكون أسرع وأكثر كفاءة في الأداء (Performance). 

في هذا الدرس، سنتناول 3 أنواع رئيسية متقدمة:

1. **List Comprehensions مع الشروط المتقدمة (If-Else):**
   الفرق هنا هو أننا لا نكتفي بفلترة العناصر (استخدام `if` وحدها)، بل نريد تطبيق عملية تبديل أو تخصيص بناءً على شرط (استخدام `if-else` كاملة).
   *الم القاعدة:* `[action_if_true if condition else action_if_false for item in iterable]`

2. **Dictionary Comprehensions:**
   تماماً مثل القوائم، ولكن لإنشاء قواميس `key: value` بطريقة ديناميكية وسريعة من أي مصفوفة أو بيانات.
   *الم القاعدة:* `{key_expr: value_expr for item in iterable if condition}`

3. **Set Comprehensions:**
   مشابهة للقوائم، ولكنها تُرجع مجموعة (`Set`)، مما يضمن تلقائياً عدم وجود عناصر مكررة.
   *الم القاعدة:* `{expr for item in iterable if condition}`

### 3. أمثلة أكواد برمجية وتطبيقات حقيقية 💻

دعنا نطبق هذه المفاهيم بأمثلة مستوحاة من العالم الحقيقي:

#### المثال الأول: تصنيف الدرجات (List Comprehension مع If-Else)
تخيل أن لديك قائمة بدرجات الطلاب وتريد تحويلها فوراً إلى تقديرات (Pass / Fail أو درجات حرفية):

```python
# درجات الطلاب
scores = [45, 82, 67, 90, 33, 76]

# استخدام Comprehension متقدم لتصنيف الدرجات
results = ["Pass" if score >= 50 else "Fail" for score in scores]

print("النتائج:", results)
# الناتج: ['Fail', 'Pass', 'Pass', 'Pass', 'Fail', 'Pass']
```

#### المثال الثاني: تحليل الأسعار (Dictionary Comprehension)
لنفرض أن لديك متجر إلكترونيات، ولديك قاموس بأسعار المنتجات بالدولار، وتريد عمل خصم 20% على المنتجات التي يزيد سعرها عن 100 دولار فقط:

```python
# الأسعار الأصلية
prices_usd = {"laptop": 1200, "mouse": 25, "monitor": 300, "keyboard": 45}

# تطبيق الخصم على المنتجات الغالية فقط، وترك الباقي كما هو
# ملاحظة: سنستخدم هنا صيغة تتيح لنا الاحتفاظ بالباقي أو تصفية المفاتيح.
discounted_prices = {
    item: (price * 0.8) for item, price in prices_usd.items() if price > 100
}

print("الأسعار بعد الخصم للمنتجات الكبرى:", discounted_prices)
# الناتج: {'laptop': 960.0, 'monitor': 240.0}
```

#### المثال الثالث: استخراج الكلمات الفريدة والطويلة (Set Comprehension)
تريد استخراج الكلمات الفريدة (بدون تكرار) والتي يتجاوز طولها 4 حروف من نص معين:

```python
text = "python is amazing and advanced python programming is very powerful"
words = text.split()

# استخراج الكلمات الفريدة التي طولها أكبر من 4 أحرف
unique_long_words = {word for word in words if len(word) > 4}

print("الكلمات المميزة الطويلة:", unique_long_words)
# الناتج (قد يختلف الترتيب لأنه Set): {'powerful', 'python', 'advanced', 'amazing', 'programming'}
```
