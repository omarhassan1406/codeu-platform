### 💡 2. الشرح العميق والمبسط

#### أ. ما هو المتغير؟ (Variables)
تخيل المتغير كأنه **"صندوق"** أو **"حاوية"** في ذاكرة الكمبيوتر، تضع بداخله قيمة معينة، وتعطيه **اسماً** لكي تستطيع استرجاع هذه القيمة أو تغييرها لاحقاً.

في بايثون، لا تحتاج إلى تعريف نوع المتغير مسبقاً، بايثون ذكي بما يكفي ليتعرف عليه تلقائياً:
```python
age = 25  # أنشأنا صندوقاً باسم age ووضعنا فيه القيمة 25
```

#### ب. أنواع البيانات الأساسية (Basic Data Types)
البيانات التي نخزنها في الصناديق أنواع مختلفة، والأربعة الأساسية هي:

1. **الأعداد الصحيحة (`int` - Integers):** أي عدد بدون كسور (موجب، سالب، أو صفر).
   * *مثال:* `10`, `-5`, `0`
2. **الأعداد العشرية (`float` - Floating-Point Numbers):** الأعداد التي تحتوي على العلامة العشرية (النقطة).
   * *مثال:* `99.99`, `3.14`, `-0.001`
3. **النصوص (`str` - Strings):** أي سلسلة من الحروف، محاطة بعلامات تنصيص (`" "` أو `' '`).
   * *مثال:* `"أحمد"`, `"Python is awesome!"`, `"123"` (حتى لو كان رقماً، طالما داخل علامات تنصيص فهو نص).
4. **القيم المنطقية (`bool` - Booleans):** تحتمل احتمالين فقط لا ثالث لهما: إما صح (`True`) أو خطأ (`False`). (لاحظ الحرف الأول كبيراً دائماً).
   * *مثال:* `is_logged_in = True`, `is_admin = False`

#### ج. التحويل بين الأنواع (Type Casting)
أحياناً تحتاج إلى تحويل البيانات من نوع إلى آخر (مثلاً تحويل رقم أدخله المستخدم كنص إلى عدد صحيح ليتم حسابه).
* `int()`: للتحويل إلى عدد صحيح.
* `float()`: للتحويل إلى عدد عشري.
* `str()`: للتحويل إلى نص.
* `bool()`: للتحويل إلى قيمة منطقية.

### 💻 3. أمثلة أكواد برمجية (تطبيقات حقيقية)

دعنا نطبق ما تعلمناه في سيناريو حقيقي لتطبيق توصيل طلبات أو متجر إلكتروني:

```python
# --- 1. تعريف المتغيرات وأنواع البيانات الأساسية ---
customer_name = "سارة أحمد"  # str (نص)
item_count = 3  # int (عدد صحيح)
item_price = 45.50  # float (عدد عشري)
is_express_delivery = True  # bool (قيمة منطقية)

# --- 2. العمليات الحسابية البسيطة ---
total_price = item_count * item_price

# --- 3. استخدام Type Casting لطباعة الفاتورة ---
# نستخدم str() لدمج النص مع الرقم دون حدوث خطأ
print("--- فاتورة الشراء ---")
print("العميلة: " + customer_name)
print("إجمالي القطع: " + str(item_count))
print("سعر القطعة الواحدة: " + str(item_price) + " دولار")
print("السعر الإجمالي المطلوب: " + str(total_price) + " دولار")
print("التوصيل السريع مفعل؟ " + str(is_express_delivery))

# --- 4. معرفة نوع البيانات باستخدام الدالة type() ---
print("\n[معلومات مطور النظام]")
print("نوع متغير total_price هو:", type(total_price))
```
