## 1. ما هي الدالة (Function) ولماذا نحتاجها؟

تخيل أنك تعمل في مطعم، وكل زبون يطلب طبق "سلطة خاص". هل ستكتب وصفة السلطة من الصفر في كل مرة يطلب فيها أحدهم الطبق؟ بالطبع لا! ستقوم بتدوين الوصفة في ورقة واحدة، وتسميتها "وصفة السلطة"، وكلما طلبها زبون، تنادي هذه الوصفة.

**في البرمجة:**
الدالة هي **كتلة من الكود المنظم القابل لإعادة الاستخدام**، تؤدي مهمة محددة. بدلاً من إعادة كتابة 10 أسطر برمجية في كل مكان، نكتبها مرة واحدة داخل دالة، ونقوم بـ "استدعائها" متى شئنا.

---

## 2. بناء واستدعاء دالة بسيطة (`def` & Calling)

لتعريف دالة في بايثون، نستخدم الكلمة المفتاحية `def` (اختصار لـ Define)، متبوعة باسم الدالة، ثم أقواس `()` ونقطتين رأسيتين `:`.

### مثال تطبيقي: نظام ترحيب في لعبة
لنتخيل أننا نبني لعبة، ونريد الترحيب باللاعبين الجدد:

```python
# 1. تعريف الدالة (Defining the Function)
pid
def greet_player():
    print("أهلاً بك يا بطل في عالم CodeU!")
    print("استعد للمغامرة!")

# 2. استدعاء الدالة (Calling the Function)
greet_player()
greet_player() # يمكننا استدعاؤها عدة مرات بكل سهولة!
```

## 3. تمرير البيانات: المُعاملات (Arguments) والقيم الراجعة (`return`)

الدوال تصبح أكثر قوة عندما تصبح **مرنة**. بدلاً من طباعة رسالة ثابتة، دعنا نجعل الدالة ترحب بأي لاعب حسب اسمه، وتُحسب نقاطه.

### تمرير المُعاملات واسترجاع القيم:
* **Arguments:** المدخلات التي نعطيها للدالة لتعمل عليها.
* **Return:** النتيجة التي تخرجها الدالة لنا لنستიدمها لاحقاً.

```python
# دالة تحسب مجموع النقاط وتضيف المكافأة
def calculate_score(current_score, bonus_points):
    total = current_score + bonus_points
    return total  # نعيد النتيجة لنستიدمها

# استدعاء الدالة وتخزين القيمة الراجعة
player_final_score = calculate_score(50, 20)
print(f"النقاط النهائية لللاعب هي: {player_final_score}")
```

> **ملاحظة ذكية:** الكلمة `return` تنهي تنفيذ الدالة فوراً، وأي كود بعدها داخل نفس الدالة لن يتم تنفيذه.

## 4. المهارات المتقدمة: القيم الافتراضية والمُعاملات المسماة

أحياناً، نريد أن يكون للمُعامل قيمة افتراضية في حال لم يقم المستخدم بإدخالها. هنا تأتي أهمية **Default Arguments**.

### مثال تطبيقي: إرسال إشعارات للمستخدمين
```python
# 'status' له قيمة افتراضية وهي "نشط"
def send_notification(username, message, status="نشط"):
    print(f"إرسال إلى [{username}] - الحالة: {status}")
    print(f"الرسالة: {message}\n-------------------")

# 1. استخدام القيمة الافتراضية
send_notification("أحمد", "لقد أكملت الدرس الأول بنجاح!")

# 2. تغيير القيمة الافتراضية باستخدام Keyword Arguments
send_notification(username="سارة", message="تم تحديث كلمة المرور", status="مشرف")
```
