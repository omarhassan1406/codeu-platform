## 1. المعاملات الحسابية (Arithmetic Operators)
في بايثون، يمكنك استخدام الكمبيوتر كآلة حاسبة خارقة. إليك جدولاً مبسطاً للمعاملات الحسابية الأساسية:

| المعامل | الوظيفة | مثال | النتيجة |
| :---: | :--- | :--- | :--- |
| `+` | الجمع | `5 + 3` | `8` |
| `-` | الطرح | `10 - 4` | `6` |
| `*` | الضرب | `4 * 3` | `12` |
| `/` | القسمة (تعطي رقماً عشرياً دائماً) | `9 / 2` | `4.5` |
| `//` | قسمة الأعداد الصحيحة (تُهمل الكسر) | `9 // 2` | `4` |
| `%` | باقي القسمة (Modulo) | `9 % 2` | `1` |
| `**` | الأسس (القوة) | `2 ** 3` | `8` (أي 2 مرفوعة للقوة 3) |

### 💡 تطبيق حقيقي: حساب إجمالي سعر السلع مع الضريبة
```python
# تطبيق عملي: حساب السعر النهائي لمنتج
item_price = 150
tax_rate = 0.15  # ضريبة 15%

# حساب قيمة الضريبة
tax_amount = item_price * tax_rate

# حساب السعر الإجمالي
total_price = item_price + tax_amount

print("سعر المنتج:", item_price)
print("قيمة الضريبة:", tax_amount)
print("السعر الإجمالي:", total_price)
```

## 2. معاملات المقارنة (Comparison Operators)
تُستخدم المقارنة لمقارنة قيمتين، ونتيجة المقارنة تكون دائماً إما **`True`** (صحيح) أو **`False`** (خطأ) - وهو ما يُعرف بنوع البيانات `Boolean`.

* `==` : يساوى (هل الطرف الأيسر يساوي الأيمن؟)
* `!=` : لا يساوى
* `>` : أكبر من
* `<` : أصغر من
* `>=` : أكبر من أو يساوي
* `<=` : أصغر من أو يساوي

```python
user_age = 20
is_adult = user_age >= 18  # هل العمر أكبر من أو يساوي 18؟

print("هل المستخدم بالغ؟", is_adult)  # النتيجة ستكون True
```

---

## 3. المعاملات المنطقية (Logical Operators)
تُستخدم لدمج عدة شروط معاً:
1. **`and` (و):** تكون النتيجة `True` إذا كانت **جميع** الشروط صحيحة.
2. **`or` (أو):** تكون النتيجة `True` إذا كان **شرط واحد على الأقل** صحيحاً.
3. **`not` (ليس):** تقوم بعكس القيمة (من `True` إلى `False` والعكس).

```python
has_ticket = True
has_visa = False

# يحتاج للسفر تذكرة وتأشيرة معاً
can_travel = has_ticket and has_visa
print("هل يمكنه السفر؟", can_travel)  # النتيجة: False
```

---

## 4. أولوية المعاملات (Operator Precedence)
تماماً كما في الرياضيات (ضرب وقسمة قبل جمع وطرح)، لْبايثون ترتيب تنفذه المعاملات به:
1. الأقواس `()` (الأعلى أولوية).
2. الأسس `**`.
3. الضرب، القسمة، وباقي القسمة (`*`, `/`, `//`, `%`).
4. الجمع والطرح (`+`, `-`).
5. المعاملات المقارنة والمنطقية.

**مثال:**
```python
result = 10 + 2 * 3
# التفسير: الضرب أولاً (2 * 3 = 6)، ثم الجمع (10 + 6 = 16)
print(result)  # النتيجة: 16
```
