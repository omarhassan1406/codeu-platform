## 🛠️ فكرة المشروع: كيف سنبني مدير المهام؟

تخيل أنك تريد تطبيقاً يتيح لك:
* إضافة مهام جديدة مع تحديد حالتها (منجزة أم لا).
* عرض جميع المهام الحالية.
* حذف مهمة تم إنجازها.
* الخروج من التطبيق بأمان.

لكي نجعل هذا التطبيق ذكياً، سنستخدم **قائمة من القواميس (`List of Dictionaries`)**. كل مهمة ستكون عبارة عن "قاموس" يحتوي على تفاصيلها (مثل: العنوان، والحالة)، وجميع هذه المهام ستجتمع داخل "قائمة" واحدة.

---

## 💻 الكود البرمجي الشامل (الكود التطبيقي)

دعونا نكتب الكود خطوة بخطوة. انسخ هذا الكود وجربه في بيئة بايثون الخاصة بك:

```python
# CodeU - To-Do List Application

# قائمة لتخزين جميع المهام
todos = []

print("=" * 40)
print("  مرحباً بك في تطبيق إدارة المهام (To-Do List) ")
print("=" * 40)

while True:
    # عرض القائمة الرئيسية للمستخدم
    print("\nاختر العملية التي تريد القيام بها:")
    print("1. عرض المهام")
    print("2. إضافة مهمة جديدة")
    print("3. حذف مهمة")
    print("4. الخروج")
    
    choice = input("أدخل رقم الخيار (1-4): ")
    
    # الخيار الأول: عرض المهام
    if choice == "1":
        if not todos:
            print("\n📌 قائمة المهام فارغة حالياً!")
        else:
            print("\n--- قائمة المهام الخاصة بك ---")
            for index, task in enumerate(todos, start=1):
                status = "✅ (منجزة)" if task["completed"] else "⏳ (قيد الانتظار)"
                print(f"{index}. {task['title']} - {status}")
                
    # الخيار الثاني: إضافة مهمة
    elif choice == "2":
        title = input("\nأدخل عنوان المهمة الجديدة: ")
        new_task = {
            "title": title,
            "completed": False # المهمة تبدأ غير منجزة افتراضياً
        }
        todos.append(new_task)
        print(f"تمت إضافة المهمة بنجاح: '{title}'")
        
    # الخيار الثالث: حذف مهمة
    elif choice == "3":
        if not todos:
            print("\n❌ لا توجد مهام لحذفها!")
        else:
            # عرض المهام أولاً ليختار المستخدم رقمها
            print("\n--- اختر رقم المهمة للحذف ---")
            for index, task in enumerate(todos, start=1):
                print(f"{index}. {task['title']}")
                
            task_num = int(input("أدخل رقم المهمة المراد حذفها: "))
            
            # التحقق من أن الرقم ضمن النطاق الصحيح
            if 1 <= task_num <= len(todos):
                removed = todos.pop(task_num - 1)
                print(f"🗑️ تم حذف المهمة: '{removed['title']}'")
            else:
                print("⚠️ رقم مهمة غير صالح!")
                
    # الخيار الرابع: الخروج من التطبيق
    elif choice == "4":
        print("\n شكراً لاستخدامك تطبيق CodeU لإدارة المهام. إلى اللقاء!")
        break
        
    else:
        print("\n❌ خيار غير صحيح، يرجى اختيار رقم بين 1 و 4.")
```

---

## 🧠 تحليل الكود (كيف يعمل؟)

1. **حلقة التكرار اللانهائية (`while True`):** تجعل البرنامج يستمر في العمل ولا ينغلق بعد تنفيذ أمر واحد، بل يست مر في استقبال الأوامر حتى يقرر المستخدم الخروج باختيار الرقم `4`.
2. **هياكل البيانات (`Lists & Dictionaries`):** استخدمنا `todos = []` لحفظ القائمة، وكل مهمة أُضيفت كـ `Dictionary` يحتوي على مفتاحين: `title` (العنوان) و `completed` (الحالة).
3. **الدالة `enumerate()`:** استخدمناها أثناء عرض المهام لنتمكن من إعطاء رقم ترتيبي للمهام (`1, 2, 3...`) يسهل على المستخدم رؤيتها وقراءتها.
4. **التحكم بالشروط (`if-elif-else`):** قامت بتوجيه البرنامج حسب المدخلات التي أدخلها المستخدم.
